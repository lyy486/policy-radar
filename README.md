# 吉林教师政策雷达免费版

个人自用的手机网页与邮件提醒工具，重点关注长春及吉林省教师考试相关公开公告。无需购买服务器，不是微信小程序。

- GitHub Actions 按工作流计划检查，发现新收录公告后发送邮件；免费调度可能延迟，不承诺实时或零漏报。
- 新来源首次读取只建立历史基线，不把旧公告群发成新消息。
- 默认关注长春及省级；网页筛选不改变邮件范围。教师资格考试与教师招聘分开标注，综合招聘线索须核对岗位表。
- 本轮配置 11 个来源，新增长春新区人才就业网的两个 HTTPS 栏目，归入长春市筛选。长春人社指定公开栏目经使用者同意采用 HTTP，传输未加密；其他 HTTP 来源仍禁用。
- 市教育局、区县及学校独立发布尚未完整接入。来源可用性须看逐源状态，不能只看任务是否运行成功。

## 使用与升级

详见 [免费手机网页版部署说明](docs/FREE-MOBILE-DEPLOYMENT.md)。升级仅使用 scripts/free-release-manifest.js 的 FREE_UPGRADE_FILES，保留云端公告历史与邮件去重文件。不要整目录上传。

邮箱地址和 SMTP 授权码只保存在 GitHub Secrets 或受保护的本机配置中，绝不要写进公开仓库。

网页和邮件只作辅助提醒。教师岗位、编制、报名资格及考试时间均须核对官方公告和附件。
